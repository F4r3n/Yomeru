# Weak kanji mnemonics

Phrases in `data/kanji-mnemonics.tsv` still worth a better idea after the review. Rewrite a line in place (never add a second line for the same kanji), then run the `--check` from the kanji-mnemonics skill.

Part names follow the real etymology (see `data/part-names.tsv`). A better phrase can also come from a better part name, but the name becomes the first meaning on that part's own kanji card.
